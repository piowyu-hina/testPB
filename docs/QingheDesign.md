# 青禾：新手角色試作

青禾是森林巡守者。村莊立繪是持槍少女；棋盤 token 則依照既有角色的設計語言，畫成棕色睡鼠小吉祥物。立繪第七版以第六版的雙手斜持槍、向前踏步姿勢與開朗表情為參照重新繪製，減少頭髮碎線、衣服零碎明暗和縮小後的視覺雜訊。舊版立繪與踏步圖保留為試作，不再由遊戲載入。露雪既有招式與圖像保留，最新雙角色擴充見 CharacterCycles.md。青禾是啟動時預設角色；村莊的選角畫面可在青禾、露雪之間切換並並排比較立繪。

## 戰鬥規則

| 卡牌 | 行動 | 落點 |
| --- | --- | --- |
| 槍刺 | 原地攻擊十字方向距離一至二格的第一隻怪物 | 人不移動 |
| 突進 | 移動到周圍八格之一；落點有怪物時攻擊 | 攻擊成功擊倒才佔據怪物格 |
| 橫掃 | 選牌後點亮起的周圍任一格，原地攻擊周圍八格所有怪物；也保留點自己施放，周圍無怪時不能出牌 | 整圈亮起，懸停整圈加亮，不加怪物紅框；人不移動，各怪物仍各自判斷正面格擋 |
| 破曉一槍 | 打出四張普通牌後點圖案施放；整條有效直線亮起，點線上任一格即可施放，對該方向所有怪物各造成兩點無視格擋傷害 | 人不移動 |

點大招圖案時先播放置中立繪，演出結束後直接選擇直線施放，不發大招卡、不佔手牌。再點圖案可取消並保留充能；有效施放才消耗充能。攻擊提示與其他玩家技能共用橘金色角框，不另加方向箭頭。魂火由左向右排，每個右側圖示的圖層低於左側，輕微重疊，不用交錯旋轉。

目前普通牌共 18 張：突進 3、槍刺 5、橫掃 4、側步 4、槍柄推擊 2。進房間先洗完整牌組，再抽三張起手；行前整備改為新房間起手四張。每成功打出一張普通牌（包含側步）充能一點，擊殺不額外充能，上限四點，跨房間保留。大招直接施放，滿手也能使用；抽牌超出的牌正常爆掉。新增循環、推擊條件、商店強化與新卡图見 [雙角色循環](CharacterCycles.md)。前進探索卡與露雪共用既有規則。

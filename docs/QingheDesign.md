# 青禾：新手角色試作

青禾是森林巡守者。村莊立繪是持槍少女；棋盤 token 則依照既有角色的設計語言，畫成棕色睡鼠小吉祥物。立繪第六版保留第五版與露雪一致的畫風，但換成青禾自己的雙手斜持槍、向前踏步姿勢，以及較開朗的表情，避免兩人的姿勢與神情雷同。舊版立繪與踏步圖保留為試作，不再由遊戲載入。露雪的圖、規則與牌組維持原樣。青禾是啟動時預設角色；村莊的選角畫面可在青禾、露雪之間切換並並排比較立繪。

## 戰鬥規則

| 卡牌 | 行動 | 落點 |
| --- | --- | --- |
| 槍刺 | 原地攻擊十字方向距離一至二格的第一隻怪物 | 人不移動 |
| 突進 | 移動到周圍八格之一；落點有怪物時攻擊 | 攻擊成功擊倒才佔據怪物格 |
| 橫掃 | 原地掃一圈，攻擊周圍八格的所有怪物 | 人不移動；各怪物仍各自判斷正面格擋 |
| 破曉一槍 | 集滿三點後領取，對任意怪物造成兩點無視格擋傷害 | 人不移動 |

每種普通牌六張，起手各一張。普通擊殺充能一點，菁英擊殺兩點，上限三點；大招卡沿用現有的五張手牌／換牌流程。普通牌沒有地面物件、撿回、額外抽牌或連鎖狀態。前進探索卡與露雪共用既有規則。

# 第五房交錯守衛試作（2026-09-28，待玩家試玩）

只改森林第五房「遺跡守衛」。噴孢菇換成同為 2 血的普通守衛，和 3 血精英守衛錯開揮枝／扎根階段；刺芽靠近入口、飛蛾在後排。仍為四隻、總血量七點，其他房間、角色、怪物招式與傷害規則不改。

設計意圖：守衛輪流露出正面破綻，玩家考慮先處理刺芽、換邊攻擊或保留走位牌。不是新 AI；沿用既有盾牌、紅格與懸停技能描述。所有攻擊先結算，之後逐隻移動並鎖定下回合預告。

最初把刺芽放在 [2,1]，會讓起點直接受威脅，違反原本安全入場約定；已改為 [1,1]。各種青禾普通牌單獨拿到時，都有一手不受傷解法。這只保證開場，不宣稱所有後續失誤都能無傷補救。

前三個候選陣形用 200 種子探索；本次 1,000 種子包含那 200 個，不是獨立盲測。無傷比例只小幅下降，仍很容易；不能當成已解決難度或已證明好玩。平均回合縮短也不代表更豐富。保留這個小範圍試作供玩家比較，不追求強制扣血。

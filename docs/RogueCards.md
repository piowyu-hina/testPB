# 露雪牌組

露雪的戰鬥核心是先用飛刀設置地上小刀，再用追影完成擊殺並回收。每回合抽 3 張牌並有 2 點能量，手牌上限為 5 張。

| 卡牌 | 費用 | 效果 |
| --- | ---: | --- |
| 飛刀 | 1 | 原地攻擊十字方向最前方的怪物，並在命中格留下小刀。 |
| 追影 | 1 | 瞬移至場上任意小刀格。格上有怪物時先攻擊；成功落地才撿刀。 |
| 突進 | 1 | 向周圍八方向移動 1 格，攻擊落點怪物。 |
| 小刀 | 0 | 原地攻擊上下左右相鄰 1 格的怪物，不移動，使用後消失。 |
| 收刃 | 0 | 原地回收任意空地飛刀，獲得小刀、恢復一點魂火並抽一張；不能回收怪物腳下的刀。 |

成功站上地上小刀或使用收刃時，先獲得一張免費小刀卡、恢復 1 點能量，再抽 1 張普通牌；全部遵守五張上限，超過部分顯示實際卡圖再爆掉，普通牌進棄牌，短暫小刀直接消散。若怪物沒有被追影擊殺，露雪不會落地，也不會撿回小刀。普通牌份數與商店強化见 [雙角色循環](CharacterCycles.md)。

怪物站在地上小刀時，攻擊傷害增加 1；離開該格後加成消失。戰鬥勝利時清除所有地上小刀。未使用的小刀卡會在回合結束時消失。

## 奧義：絕影

擊殺普通怪物獲得 1 點殺意，擊殺菁英獲得 2 點。殺意上限為 3 並跨房間保留。下方絕影圖案由下往上填滿；集滿後發亮，點擊播放置中立繪演出，再選怪物直接施放。再次點圖案可取消且保留充能；有效出手才消耗，不發大招卡、不佔手牌，也不進入換牌畫面。充能跨回合、跨房間保留，換角色時清除。普通抽牌及未來產牌型大招都遵守五張上限，超出的牌顯示卡圖並播放爆牌動畫，之後進棄牌堆；不需要重複文字提示。

點擊絕影圖案、演出結束後選擇場上任意怪物，造成 2 點傷害並無視正面格擋。成功擊殺時落在怪物原本的格子；未擊殺則返回原位。使用後充能歸零。

規則資料位於 `src/data/cards.ts` 與 `src/battle/Room.ts`，畫面互動位於 `src/screens/BattleScreen.ts`。

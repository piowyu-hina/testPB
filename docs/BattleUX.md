# 戰鬥操作體驗

- 未選牌時提示「選牌 → 點亮起的格子」，選牌後持續顯示走法及再次點牌取消；無合法落點時提示換牌。
- 移動預覽顯示落點的敵方攻擊傷害，標示是否還可行動及致命風險。正面格擋有獨立提示。
- 行動菱形旁顯示剩餘次數；結束回合按鈕旁顯示留在原地的受傷預告。數值使用既有 Room 預覽與傷害規則。
- 清場後提示使用探索卡走向上方出口、恢復生命；不增加下一間按鈕。
- 進入下一間後顯示約一秒的房間名稱與恢復狀態，實際新增的生命愛心亮起；滿血只顯示「生命已滿」。轉場期間保持操作鎖定，結束後自動消失。
- 「玩法」說明可隨時開啟；關閉後保留已選卡牌，不新增鍵盤操作。
- 一擊擊敗時直接移到目標格，命中短停 80ms 後怪物直接消失，沒有閃光、縮小或淡出。一般移動 130ms、跳躍 180ms，以快速起步改善滑動感。未擊敗則停在怪物前方，怪物受擊後退並短暫變亮，角色再退回原位。正面格擋顯示停留約半秒的藍盾後退回，沒有細碎光圈。
- 玩家受傷時短暫變紅並沿攻擊方向後退，生命顯示同步更新。清場出口持續微亮，減少動態效果設定下停止呼吸動畫。
- 短暫特效由 `ui/battleFeedback.ts` 管理，等待完成後移除；不在怪物頭上加入文字，不改戰鬥數值或回合規則。

以開發視窗驗證。`tests/battle-ux.cjs` 檢查選牌提示、說明視窗、取消選牌和預告；完整 browser-check 包含此流程。

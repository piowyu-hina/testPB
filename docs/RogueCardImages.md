# 盜賊卡牌圖片

卡牌圖放在 `assets/cards/rogue/`，由遊戲既有的卡框呈現。

- `Throw.png`：飛刀與動作軌跡。
- `Shadow.png`：白色垂耳狗向飛刀突進。
- `Whirl.png`：白色垂耳狗旋身攻擊。
- `Knife.png`：白色狗掌握著短刀。
- `Forward.png`：白色垂耳狗沿石路前進，清場後的探索牌使用。

`Shadow.png`、`Whirl.png`、`Knife.png` 與 `Forward.png` 參照棋盤角色 `assets/characters/rogue/Token.png`，讓牌面動作和棋盤小人能被辨認為同一角色。非盜賊角色的「前進」牌仍用移動圖示，避免出現錯誤角色。

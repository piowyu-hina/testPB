# 素材分類

- `characters/rogue/`：目前試用的黑髮短刀女孩立繪與不對稱白色吉祥物棋子。
- `characters/heroine/`：前一版角色立繪與棋盤圖，保留供比較。
- `monsters/forest/`：森林怪物。
- `scenes/village/`：村莊背景。
- `scenes/forest/`：森林遺跡背景。
- `drafts/rogue/`：黑髮短刀女孩與白色吉祥物原圖；試用副本位於 `characters/rogue/`。
- `archive/monsters/`：目前未使用的舊怪物圖，保留備查。

新角色、怪物與場景各自新增子資料夾。候選圖先放 `drafts/`，採用後再移入正式分類並更新引用。原始圖片保留原檔名；整理不修改圖像內容。

角色與怪物引用集中在 `src/data/art.ts`；場景圖由各場景資料或 Screen 引用。`art-previews/` 保留既有試作歷史。

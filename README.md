# testPB

直接雙擊 **index.html**，用 Chrome 或 Edge 開啟即可。無須 Unity、Node.js、安裝套件或本機伺服器，也不需要網路。

## 操作

- 點一張牌，再點棋盤上框出的格子。
- 滑鼠停在合法落點上，可以預覽移動、擊殺和剩餘危險。
- 再點同一張牌，或點棋盤外的空白處，可取消選牌。
- 每回合最多兩步；也可以按右側按鈕提前結束回合。
- 過關或失敗後可再來一局。
- 只使用滑鼠／觸控，沒有鍵盤遊戲操作。

## 本版內容

5 × 5 棋盤、一位冒險者、五點生命、四種步法、赤角與暮翼兩種敵人。

短步：直向一格。斜步：斜向一格。突進：直向恰好兩格，不能穿越敵人。躍步：斜向恰好兩格，可以跳過中間敵人。只有落點會攻擊。

敵人先依目前顯示的範圍攻擊，再移動並預告下一回合。暖色格表示危險，每個紅色菱形代表一點傷害。最後一隻敵人被擊敗即過關，不再結算敵方回合。

開場位置和手牌固定；重玩會改變後續洗牌。牌組共十二張，每種三張。

## 檔案

- `data/cards.js`：卡片定義與敵人定義，對應原本 SO 的資料用途。`offsets` 是相對落點，y 正值向上；`canJump` 表示可否越過途中敵人。
- `src/rules.js`：純遊戲規則，預覽與實際行動共用判定。
- `src/game.js`：滑鼠操作、呈現和動畫。
- `src/style.css`：版面與 UI。
- `assets/`：沿用已生成的透明角色 PNG，未重新繪製。
- `docs/ArtPrompts.md`：原始美術提示詞記錄。

卡片資料採一般 JavaScript 物件，方便直接用 `file://` 開啟，不需要 fetch 或伺服器。修改資料後重新整理網頁即可。若新增卡片種類，可設定 `copies` 加入牌組；走法圖與合法落點會讀取同一份定義。更複雜的新效果仍需增加規則處理。

## 開發檢查

執行 `node --test tests/rules.test.cjs`。Node.js 只供開發檢查使用，不是玩遊戲的必要條件。

這是獨立 HTML 原型，沒有 Electron、npm 執行期依賴、遙測、CDN 或外部請求。使用電腦上的微軟正黑體，其他環境以系統字體替代。
